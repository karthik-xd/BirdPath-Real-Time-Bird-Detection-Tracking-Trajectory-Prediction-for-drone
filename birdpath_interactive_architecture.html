DECISION GATE 1: Detection Score Threshold
Is bounding box raw confidence ≥ 0.25 (eval: 0.30)?
✓ YES (Candidate Retained)
Box passes to ByteTrack partitioner. If score ≥ 0.50, routed to High-Confidence Pool (Stage 1). If 0.10 ≤ score < 0.50, routed to Low-Confidence Remnant Pool (Stage 2).
✗ NO (score < 0.10)
Discarded immediately as false positive camera noise, insect, or cloud edge artifact. Kalman filter continues in pure kinematic predict-only mode.
DECISION GATE 2: ByteTrack Two-Stage Hungarian Matching
Does high-conf detection IoU match an existing active track?
✓ MATCHED (Stage 1 or Stage 2)
Kalman update applied: y = z - Hx, K = P·Hᵀ·inv(S), x = x + K·y. Track time_lost reset to 0. Historical coordinate buffer appended with current CoM position.
✗ UNMATCHED TRACK / NEW TARGET
If unmatched high-conf detection: initialize new TENTATIVE track (confirmed after 3 consecutive hits). If unmatched active track: increment time_lost; if time_lost > 90 frames, purge track.
DECISION GATE 3: Trajectory Forecasting Mode
Does track have sufficient history (N ≥ 15 frames)?
✓ YES (N ≥ 15 frames)
Construct normalized (15, 6) history tensor. Execute 2-layer GRU forward pass to predict 20 non-linear future waypoints with heteroscedastic uncertainty bounds.
⚠ FALLBACK (N < 15 frames)
Kinematic Fallback Extrapolator: projects future waypoints using 8D Kalman filter linear velocity vector [vx, vy]. Once track reaches 15 frames, GRU seamlessly takes over.
DECISION GATE 4: Autonomous UAV Collision Hazard Check
Is target distance ≤ 50m AND Time-to-Closest-Approach (TCPA) ≤ 2.5s?
🚨 IMMINENT COLLISION THREAT
Trigger auditory/visual red HUD alarm. Compute 90° orthogonal escape break angle (θ_escape = θ_bird ± 90°). Dispatch MAVLink #147 emergency waypoint with 95% climb throttle burst.
✓ CLEAR AIRSPACE (Safe Separation)
Target outside critical safety envelope. Render nominal 3D green/cyan flight corridor with arrival time badges (+1s, +2s, +3s). Maintain mission flight plan.
