# Model Assets Directory

Place the exported TFLite models in this directory before building the release APK:

1. `yolov8n_bird.tflite`
   - Generated by: `python python/train_detector.py --export`
   - Expected Input: `(1, 640, 640, 3)` Float32 or UINT8
   - Expected Output: `(1, 5, 8400)` [cx, cy, w, h, bird_score]

2. `bird_trajectory_fp16.tflite`
   - Generated by: `python python/export_tflite.py --ckpt checkpoints/best_gru.pt --tflite android/app/src/main/assets/bird_trajectory_fp16.tflite`
   - Expected Input: `(1, 15, 6)` Float32 [cx, cy, w, h, dx, dy]
   - Expected Output: `(1, 20, 4)` Float32 [mean_dx, mean_dy, logvar_dx, logvar_dy]

Note: If models are not present, the app automatically falls back to the Constant-Velocity Kalman Predictor baseline.
